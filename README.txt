CEYLON NOIR - PREMIUM BLACK & GOLD TEA E-COMMERCE v2
====================================================

This student project is a PHP + MySQL e-commerce website for premium Ceylon tea products.

NEW IN v2
----------
* Premium black + gold visual design across home and inner pages
* Full product filtering: search, category, minimum price, maximum price
* Product sorting: Featured, Newest, Price Low-High, Price High-Low
* Category filter pills
* 10 seeded tea products with richer product information
* Detailed product pages with origin, weight, tea type, tasting notes, brewing guide and stock
* Premium product-card hover effects and luxury collection banner
* Responsive layout for desktop/tablet/mobile

TECHNOLOGY
----------
HTML, CSS, JavaScript/PHP, MySQL, XAMPP

XAMPP SETUP
-----------
1. Copy the Ceylon_Tea_Website folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin.
4. Import database.sql. It creates the ceylon_tea database and sample products.
5. Open: http://localhost/Ceylon_Tea_Website/

DATABASE CONFIG
---------------
config.php uses:
Host: localhost
User: root
Password: blank
Database: ceylon_tea

If your MySQL password is different, edit config.php.

IMPORTANT
---------
The database.sql file is intended for a fresh/demo setup and resets the products table so the supplied product catalogue is loaded.
