CEYLON TEA - BLACK & GOLD E-COMMERCE WEBSITE

Requirements
- XAMPP (Apache + MySQL)
- PHP 7.4+ recommended
- MySQL/MariaDB

INSTALLATION
1. Extract this folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin/
4. Import database.sql (or paste/run it in the SQL tab).
5. Confirm the database name is ceylon_tea.
6. Open http://localhost/Ceylon_Tea_Website/

FEATURES
- Luxury black & gold responsive design
- Home page with tea imagery and categories
- Database-driven product catalogue
- Category filtering
- Session shopping cart
- Customer registration/login/logout
- Checkout and order creation
- Order success page
- About and Contact pages

DATABASE
The database.sql file creates users, products, orders and order_items tables and inserts starter products.

IMPORTANT
For a real public deployment, change the database credentials in config.php, use HTTPS, and do not use a blank MySQL root password.
